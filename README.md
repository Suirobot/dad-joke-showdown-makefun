A fresh dad joke about a beloved sourdough starter that finally couldn't rise to the occasion — one clean pun, delivered deadpan, built to earn the biggest groan at the table. The program writes the joke to `/output/entry.txt`, where make.fun's house judge reads it head-to-head against the other entries.

## Run it

```sh
node main.ts
```
